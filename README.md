# DS_Project2
This application uses student academic performance and dropout risk data to explore factors associated with student success and persistence. Users can filter the dataset to focus on specific groups of interest based on demographic, academic, and personal characteristics.

The Data Download tab allows users to view and download the filtered dataset for further analysis. The Data Exploration tab provides a variety of tools for investigating relationships within the data, including visualizations such as histograms, boxplots, scatterplots, density plots, and heatmaps, as well as one-way and two-way frequency tables and numerical summary tables.

Explore the data to identify patterns and characteristics associated with academic performance and student dropout risk.
